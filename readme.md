# Python Object-Oriented Programming Studies

This repository contains a collection of practical exercises and projects developed to master **Object-Oriented Programming (OOP)** concepts using Python.

## Core Concepts Implemented

- **Classes & Objects**: Creating blueprints and managing instances.
- **Attributes & Methods**: Defining object states and behaviors.
- **Dependency & Association**: Handling communication between different objects.
- **Exception Handling**: Implementing data validation using `try/except` and `raise`.
- **Naming Conventions**: Following **PEP 8** (PascalCase for classes, snake_case for methods).
